Post Averaging

pysammos.post_averaging package

Subpackage for averaging slices of the results after the Coarse Graining process to obtain profiles in any dimension.

Profiles module

pysammos.post_averaging.profiles

Post-hoc spatial averages of coarse-grained fields: over a whole region, or as a profile along x, y or z.

The coarse-grained fields are split in primary fields (kernel-weighted sums over particles: volume fraction, mixture density, momentum density, kinetic, fluctuation and contact tensors, ...) and derived fields (nonlinear functions of them: velocity, shear rate, pressure, granular temperature, inertial number, frictional coefficient, ...), see pysammos.macroscopic_fields.gridded.derived_fields.

As for the time averages, only the primary fields are averaged (with the same weights, pysammos.time_average.accumulator.summable_terms()), and the derived fields are then computed from the averages with the same code as for one time step:

  • velocity: averaged momentum density over averaged mixture density (Favre average),

  • velocity gradient: along a profile, finite differences of the profile velocity; across the averaged directions (and for a whole-region average), the slope of a least-squares fit of the grid-node velocities, weighted by the mixture density. On a 2D grid the collapsed direction has a zero gradient.

  • granular temperature, stresses, pressure, shear rate, inertial number, frictional coefficients: from the above.

Averaging the derived fields themselves ("naive" average) is biased wherever they vary within the averaged region, e.g. the mean of \(1/\sqrt{p}\) exceeds \(1/\sqrt{\bar p}\). The primary fields are written by CoarseGraining with export_primary_fields=True (default); for files without them the naive average is only computed if the user agrees.

Note that the kinetic and fluctuation tensors at each grid node are measured relative to the velocity at that node: the spatial variation of the coarse-grained velocity within the averaged region (\(\rho (u - \bar{u}) \otimes (u - \bar{u})\)) is not included in the averaged stress or temperature.

This module contains:

  • SpatialAverager with mean() (one value per time step over a region) and profile() (profile along an axis, within a region),

  • VerticalIntegrator, the former interface (a profile over the whole grid).

Example

>>> ds = H5XarrayManager("CG_Lucy_Monodisperse.h5").h5_to_xarray()
>>> averager = SpatialAverager(ds, region={"x": (0.1, 0.3)})
>>> prof = averager.profile("y")       # profile along y of the region 0.1 <= x <= 0.3
>>> bulk = averager.mean()             # one value per time step over the region

class pysammos.post_averaging.profiles.SpatialAverager(ds, region=None, naive=None)[source]

Bases: object

Spatial averages of the coarse-grained fields of an .h5 output, over a region of the grid.

Inputs

dsxr.Dataset

Coarse-grained output read with H5XarrayManager.h5_to_xarray() (time series or time average).

regiondict, optional

Limits of the region to average, e.g. {"x": (0.1, 0.3), "z": (None, 0.05)} (inclusive, None for no limit). Axes not given are not limited. Default is the whole grid.

naivebool or None, optional

What to do with requested fields whose primary fields are not in ds: True: average the fields themselves (biased, listed in the attribute naive_average); False: raise an error; None (default): ask the user.
